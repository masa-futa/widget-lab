# 機能設計: プロパティの選ぶ欄（‹ カード › とインジケーター）

> **要約**
> - 結論: 詳細画面の「仲間のタブ＋チップの列」をやめ、今のプロパティを 1 枚のカードで見せる選ぶ欄にする。左右の丸い ‹ › で 1 つずつ送り、下の点で全体の位置と指定中を示し、カードを押すと全部を仲間ごとの見出しで並べた一覧のシートを開く
> - 影響: 詳細画面（cb_dtl）の pc・gt・rf・ne、DetailState と DetailNotifier の仲間のタブまわり、値の短い表示（`chipValueLabel`）、Figma に v4 を足す
> - お願い: なし（2026-10-29 にオーナーとブラウザの見本で決めた）

## 背景

実機で触ったオーナーの感想（2026-10-29）: 「`child OverflowBox(maxWidth: 120, ...)` のようなところの情報量が大きくなると、見た目がかなり悪くなる。パラメーターの選択をもっと簡単にしたい」。

チップには「名前＋今の値」を出しており、変えられない値（`FixedControl`）はコードの書き方がそのまま出る。収録の 180 件のうち 20 文字を超えるものが 86 件、40 文字を超えるものが 24 件ある（最長は 100 文字の `Padding(padding: EdgeInsetsDirectional.only(end: 8), child: Icon(...))`）。長いチップが 1 つあると、横にスクロールする列に入るチップが 1〜2 個になり、ほかのプロパティを探しにくい。段 2 でプロパティが増え、1 Widget の最大は 21 件（TextField・TabBar）。

## 決めたこと

| 項目 | 決定 |
|---|---|
| 選び方の形 | 選ぶ欄を 1 つにする。真ん中に今のプロパティのカード、左右に丸い ‹ ›、下にインジケーターの点 |
| カードを押したとき | 下からシートを開き、全部のプロパティを仲間ごとの見出しで並べる。選ぶと閉じる |
| 仲間のタブ | やめる。仲間はシートの見出しと、カードのアイコン・点の間で示す |
| 補足 | シートの最後に「補足」の行を置く。‹ › でも最後に届き、選ぶと編集パネルに今と同じ一覧を出す |
| 送り方 | ‹ › のタップだけ。スワイプは入れない。端では押せなくし、回りこまない |
| 入れ子の子 | 編集パネルの中の子のチップは残す。値の短い表示の決まり（下）を当てる |
| Figma | v4 のフレームを足してから実装する |

採らなかった案（ブラウザの見本で比べた）:

- チップのまま値を短くする: 変更は小さいが、横スクロールで端の外が見えない性質が残る
- 縦のリスト（押すとその場で開く）・2 列のタイル: 見渡せるが、プレビューの下の高さを大きく使い、編集パネルが狭くなる
- 下に広がるメニュー（DropdownMenu）: 編集パネルに重なり、21 件では窮屈
- 目盛り（なぞって選ぶ）: 一目で分かるが、21 件では 1 本が細く狙いにくい
- カルーセル（隣のカードがのぞく）とカード＋点の組み合わせ: オーナーが「組み合わせるとくどい」。点だけ残し、のぞきはやめた
- 今のタブに絞ったシート: タブが残り、別の仲間を選ぶのに 2 手かかる

## 画面の並び

上から「アプリバー → プレビュー → コードの帯 →（ログの帯）→ 選ぶ欄 → 点 → 編集パネル」。仲間のタブ（gt）とチップの列（pc）はなくす。

選ぶ欄と点の高さは約 72pt（カード 56＋点の行 16）。今のタブ（48）とチップ（48）を合わせた約 96pt より低いので、段 2 で足した「キーボードが出ている間は仲間のタブを隠す」決まりは要らなくなり、消す。プレビューの高さの割り当て（`middleHeight`）は、タブとチップの代わりに選ぶ欄と点の高さを入れる。

ただしキーボードが出ている間は、編集パネルの高さを守るため点の行（16）を隠す。カードと ‹ › は出たままにし、`middleHeight` もそのとき点の高さを入れない。

プロパティが 1 つで補足もない Widget は、‹ › と点を出さずにカードだけを出す（押すとシートは開く）。プロパティが 0 件の Widget は今と同じく何も出さない。

## 送る順番

シートの並びと、‹ ›・点の順は同じにする。

1. 仲間のないプロパティ（`group` が `null`）を収録の順に
2. 仲間を `PropertyGroup` の語彙の順（大きさ・余白・配置・色と装飾・変形・文字・挙動・中身）に。中は収録の順
3. 補足（`references` があるときだけ）

今のチップの列は「開いているタブの仲間」を収録の順に並べていたので、仲間をまたいだ順番はこれが初めて決まる。開いたときに選んでいるプロパティは今と同じ（最初の ON のプロパティ、なければ先頭）。

## 選ぶ欄（ps）

### カード

- 中身: 仲間のアイコン・名前（1 行）・「{仲間} ・ {値}」（1 行）・右端に ⌄。名前と値は収まらなければ末尾を「…」にする。値は下の「値の短い表示」
- 見た目はチップの決まりをそのまま使う: 指定中（ON）は `accent` の塗りで文字は白、既定（OFF）は枠だけで値は「既定」、`requires` の相手が OFF で効かないものは 50% の不透明度
- 補足を選んでいるときは、アイコン `notes`・名前「補足」・「{n} 件 ・ 読むだけ」。枠だけ
- 高さ 56（文字を大きくしたら中身に合わせて高くする）、角丸は `NimiRadius` の md（12）、押せる範囲は全体

### 丸い ‹ ›

- 直径 40 の丸、押せる範囲 48×48。地は `accent-container` の薄い色、記号は `accent`
- 先頭では ‹、最後では › を非活性にする（薄くして押せない）
- 押すと前後のプロパティを選ぶ。比較中ならやめる（見た目を持たない Widget は今のチップと同じく比べるのを続ける）

### 点（インジケーター）

- 1 つのプロパティに 1 つの点（6×6）。間は 4、仲間の境目は 8 空ける。補足は最後に、境目を空けて輪（中を塗らない点）で出す
- 今の位置は横に長い点（18×6、`accent`）。指定中は `accent` の薄い色、既定は `outline` の薄い色
- 飾りとして扱い、押せない・読み上げない。21 件と補足で約 300pt になる。画面の幅に収まらないときは、全体を縮める（`FittedBox`）。キーボードが出ている間は点の行ごと隠す（高さ 16 を編集パネルに回す）

### アイコン（仲間ごと、Material Icons）

| 仲間 | アイコン |
|---|---|
| なし | `tune` |
| 大きさ | `aspect_ratio` |
| 余白 | `padding` |
| 配置 | `align_horizontal_center` |
| 色と装飾 | `palette` |
| 変形 | `transform` |
| 文字 | `text_fields` |
| 挙動 | `touch_app` |
| 中身 | `widgets` |
| 補足 | `notes` |

### 読み上げ

- カードは「調整できる項目」として扱う（`Semantics` の `onIncrease` / `onDecrease`）。読み上げは「{名前}、{仲間}、{値}、{i} / {n}」。上下のスワイプで前後に送り、ダブルタップでシートを開く
- ‹ › はそれぞれ「前のプロパティ」「次のプロパティ」のボタン

## 一覧のシート（pss）

- 今の説明・コードのシートと同じ `showDetailSheet` で開く。題は「プロパティ（{n}）」、横に「指定中 {m}」
- 仲間ごとに見出し（アイコン＋仲間の名前）を付け、行は「● / ○ 名前 …… 値」。● は指定中、○ は既定。名前は行の幅の 60% までで、値は残りを使って右にそろえ、長ければ「…」にする。効かないものは 50% の不透明度
- 今選んでいる行は `accent-container` の地と ✓
- 最後に「補足」の見出しと「{n} 件」の 1 行
- 行を押すとそのプロパティ（または補足）を選んでシートを閉じる。比較中なら ‹ › と同じく扱う
- 開いたときは、今選んでいる行が見える位置まで送る

## 値の短い表示

カード・シートの行・入れ子の子のチップで同じ決まりを使う（`chipValueLabel` を直す）。

- スライダー: 今と同じ（整数なら小数点を省く）
- 変えられない値（`FixedControl`）: 20 文字までは書き方のまま（末尾の `()` を省くのは今と同じ）。超えるときは先頭の型の名前だけにする。`[` で始まるものは `[型の名前]` にする
  - 例: `OverflowBox(maxWidth: 120, maxHeight: 56, child: Tile(1))` → `OverflowBox`、`[BoxShadow(blurRadius: 12, ...)]` → `[BoxShadow]`、`Color(0x40000000)` → そのまま
- ほか（選択肢・文字・色）: 今と同じ。長いものは表示の側で「…」にする
- 完全な書き方は、編集パネルとコードの帯で今と同じく見られる。読み上げには完全な値を使う

## 関係の行・入れ子・補足（今からの変わり方）

- 関係の行（rl）の相手の名前を押したとき: 「相手のタブを開き、相手を選ぶ」をやめ、「相手を選ぶ」（カードがそこへ移る）にする
- 入れ子（ne）: 子のチップの列は残す。値に上の短い表示を使う
- 補足（rf）: 補足のタブを開いていたときと同じく、編集パネルの代わりに一覧を出し、「比べる」「既定に戻す」を出さない。コードの帯は最後に選んでいたプロパティの行のまま

## 状態とイベント（DetailState・DetailNotifier）

- やめる: `selectedGroup`・`showsTabs`・`specsInSelectedGroup`・`onCountIn`・`groupSelected`
- 足す: 送る順番の一覧（プロパティの名前と、最後に補足）、今の位置、前後があるか
- 足す: `previousTapped()`・`nextTapped()`（前後を選ぶ。補足に入る・補足から出るのも扱う）
- そのまま: `propertySelected`・`referencesSelected`・`showsReferences`・`selectedChild`
- 送る順番は `WidgetEntry` から決まるので、収録データ（`lib/catalog/`）は変えない

## テスト

- `chipValueLabel`: 20 文字までの書き方・型の名前だけにするもの・`[` で始まるもの・スライダー（単体）
- DetailState の送る順番: 仲間のないもの → 語彙の順 → 補足。端の判定（単体）
- DetailNotifier: ‹ › で前後に移る、補足へ入る・出る、比較中はやめる（見た目を持たない Widget は続ける）（単体）
- 選ぶ欄: 端で ‹ › が非活性、指定中・既定・効かないの見た目、1 件だけのときは ‹ › と点を出さない、文字を大きくしてもはみ出さない（Widget）
- シート: 仲間の見出しの順、行を押すと選んで閉じる、補足の行（Widget）
- 読み上げ: カードの `onIncrease` / `onDecrease` で送れる（Widget）
- 全件: 画面を開く代わりに状態で、212 件すべての送る順番を確かめる（TC-92）
- 消す: 仲間のタブのテストと、キーボード中にタブを隠すテスト
