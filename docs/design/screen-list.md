## 命名規則

### ID

`<大分類の英小文字1字><中分類の英小文字1字>_<英小文字3字>`。大分類・中分類は下の表で決め、末尾3字は重ならないように付ける（意味は持たせない）。

| 大分類 | 字 | 中分類 | 字 |
|---|---|---|---|
| カタログ | c | 一覧 | a |
| | | 詳細 | b |
| 共通・その他（エラー・ローディング・汎用） | z | 汎用 | b |

### 日本語名 / 英語名

| 画面種別 | 日本語名 | 英語名 | タブがあるとき |
|---|---|---|---|
| スクリーン | 〜画面 | 〜Screen | `<親画面名>_<タブ名>タブ` |
| コンポーネント（画面の中で使い回す部品） | 〜アイテム | 〜Item | 該当なし |

### 実装種別
